# TypeScript-React

### Projeto acadêmico de estudos em TypeScript, React e Programação Orientada a Objetos

Este repositório reúne estudos e práticas de desenvolvimento de software com **TypeScript** e **React**, com ênfase nos fundamentos da **Programação Orientada a Objetos (POO)** e na aplicação desses conceitos em projetos para a web.

O trabalho tem caráter acadêmico e é desenvolvido com o acompanhamento do **professor Bruno Zolotareff**. A proposta é aprender por meio da prática: explorar ferramentas e conceitos, organizar o código e construir uma base sólida para o desenvolvimento de aplicações.

## Objetivos

- Aprender e aplicar os fundamentos de TypeScript;
- Estudar conceitos de POO e sua utilização na organização do código;
- Praticar o desenvolvimento de interfaces e aplicações com React;
- Compreender a estrutura de um projeto web e a relação entre seus componentes;
- Desenvolver boas práticas de programação por meio de exercícios e experimentação.

## Tecnologias

- **TypeScript** — linguagem principal de estudo;
- **React** — biblioteca para desenvolvimento de interfaces;
- **CSS** — estilização das interfaces;
- **JavaScript e HTML** — tecnologias que complementam a aplicação web.

## Contexto acadêmico

Este projeto faz parte de um processo de aprendizagem orientado, no qual os conteúdos são explorados e aplicados progressivamente. Mais do que apresentar um produto final, o repositório documenta a prática dos conceitos estudados e a evolução no uso de tecnologias e técnicas de desenvolvimento.
